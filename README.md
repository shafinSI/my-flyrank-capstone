## Evidence note
The supplied project snapshot contains weekly notebooks using synthetic/mock fixtures but does not contain the claimed production 79-million-row extract or the original `capstone.ipynb`. The public paper therefore labels its numeric results as synthetic-fixture audits and avoids production-scale or causal claims.

## GitHub Pages
A GitHub Actions workflow under `.github/workflows/pages.yml` publishes the `docs/` directory. GitHub Pages supports static files and Actions-based deployment.
